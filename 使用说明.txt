基于单片机的电子密码锁——使用说明
适用：STM32F103C6、LCD1602、4×4 矩阵键盘、PA1 高电平蜂鸣器

一、功能与课设要求对应
1. 使用 STM32F103C6 实现电子密码锁。
2. 使用矩阵键盘输入六位数字密码，可以设置和修改密码。
3. 连续三次完整密码验证错误后，蜂鸣器报警并由 LCD 提示。
4. LCD 显示当前工作状态；C 键用于退格，删除最后一位。

二、开始使用
1. 打开“仿真”文件夹中的“STM32F103C6.pdsprj”。
2. 双击单片机 U1，检查 Program File 指向同一文件夹中的“密码锁.hex”。
   如果复制项目后路径失效，重新选择这一个 HEX 文件即可。
3. 启动仿真。LCD 应显示：
   第一行：LOCKED A:OPEN
   第二行：B:CHANGE PWD
   这表示当前处于锁定状态，蜂鸣器不响。
4. 上电默认密码为 123456。每次按下一个键后要松开，再按下一个。

三、按键说明
0～9：输入数字密码，共六位；前导 0 有效。
A：在主菜单进入开锁密码输入。
B：在主菜单进入密码设置/修改，先验证当前密码。
C：退格，只删除当前输入的最后一位；输入为空时不产生变化。
D：确认当前输入；开锁状态下也可提前返回锁定状态。
*：取消当前操作，返回主菜单；开锁状态下也可提前上锁。
#：清空当前输入的全部数字。

C 和 # 只编辑正在输入的内容，不会删除已经设置的密码。
密码输入均显示为星号，不显示实际数字。超过六位的额外数字不会录入。
短暂错误提示结束后再继续按键；报警期间全部按键被屏蔽。

四、正常开锁
以默认密码 123456 为例：
1. 在主菜单按 A。
   LCD 第一行显示 ENTER PASSWORD，第二行显示 PWD:。
2. 依次输入 1、2、3、4、5、6。
   第二行显示 PWD:******。
3. 按 D 确认。
   第一行显示 PASSWORD OK，第二行显示 OPEN 3s D:LOCK。
4. 显示开锁状态 3 秒后自动返回锁定主菜单，也可按 D 或 * 提前返回。

正确密码可以重复使用，开锁后不会清除密码。
本图只有蜂鸣器，没有电锁或继电器；开锁结果通过 LCD 状态表示。
正常开锁期间 PA1 为低电平，蜂鸣器不响。

五、第一次设置自己的密码，以及以后修改密码
第一次使用时，以默认密码 123456 作为当前密码。
以后修改时，使用上一次成功设置的密码作为当前密码。
例如，把默认密码改为 654321：
1. 主菜单按 B。
   LCD 显示 VERIFY OLD PWD，要求验证当前密码。
2. 输入 123456，按 D。
   验证通过后显示 NEW PWD:6 DIGITS。
3. 输入新密码 654321，按 D。
   显示 REPEAT NEW PWD，要求再输入一次。
4. 再输入 654321，按 D。
   显示 PASSWORD CHANGED / LOCKED，稍后返回主菜单。
5. 按 A → 输入 654321 → 按 D，应显示 PASSWORD OK。
   此时旧密码 123456 已失效。

如果两次新密码不同，显示 PWD MISMATCH / ENTER NEW AGAIN，
稍后回到新密码输入界面；原密码仍然有效，需要重新输入并确认新密码。
修改过程中按 * 取消，原密码保留。
密码修改过程不会触发蜂鸣器。

六、退格、清空与位数不足
退格示例：
原本要输入 123456，却输入了 123459。
按 C 后最后一位 9 被删除，星号由六个变成五个；再按 6，然后按 D。
此时实际提交的是 123456。

清空示例：
输入若干数字后按 #，星号全部消失，可从第一位重新输入。

位数不足示例：
输入 12 后按 D，显示 NEED 6 DIGITS / C:DEL D:CONFIRM。
约 1 秒后回到输入界面，保留已经输入的 12；再输入 3456 后可按 D。
开锁、验证旧密码、输入新密码和重复新密码界面均遵循此规则。
不足六位不计入密码验证错误次数。

七、连续三次输错报警
每次“输入完整六位错误密码并按 D”计为一次验证失败。
默认密码为 123456 时，可以用 000000 测试：
1. 按 A，输入 000000，按 D。
   显示 PASSWORD ERROR / TRIES LEFT: 2。蜂鸣器不响。
2. 等待提示结束，再输入 000000，按 D。
   显示 PASSWORD ERROR / TRIES LEFT: 1。蜂鸣器仍不响。
3. 等待提示结束，第三次输入 000000，按 D。
   PA1 输出高电平，蜂鸣器连续响；LCD 显示报警文字和 30 秒倒计时。
   第一行交替显示 !!! ALARM !!! 与 3 WRONG PASSWORD。
   第二行显示 RETRY IN 30s，并逐秒更新。
4. 报警期间按 A、B、C、D、*、# 或数字键均不能解除报警。
5. 30 秒结束后 PA1 自动拉低，蜂鸣器停止，返回锁定主菜单。
   错误次数清零，可以重新输入正确密码。

计数规则：
- 按 * 返回主菜单、按 # 清空或按 C 退格，不会清零错误次数。
- 开锁和修改密码中的旧密码验证，共用同一错误计数。
- 正确验证当前密码后，连续错误计数清零。
- 两次新密码不一致属于修改确认失败，不计入密码验证错误次数。

八、建议验收顺序
每一项的预期结果如下，可按顺序演示：
1. 上电：显示锁定主菜单，蜂鸣器静音。
2. 默认密码开锁：A → 123456 → D；显示开锁，3 秒后返回。
3. 退格：A → 123459 → C → 6 → D；开锁成功。
4. 清空：A → 999 → # → 123456 → D；开锁成功。
5. 设置新密码：B → 123456 → D → 654321 → D → 654321 → D；提示修改成功。
6. 新密码开锁：A → 654321 → D；开锁成功。
7. 旧密码失效：A → 123456 → D；提示错误；随后输入 654321 → D，应开锁成功并清零计数。
8. 三次错误报警：用 000000 连续提交三次；蜂鸣器响 30 秒，期间不能操作。
9. 报警恢复：30 秒后用 654321 开锁，蜂鸣器保持静音。

九、复位与密码保存
当前密码暂存在 RAM 中。
停止后重新启动仿真、断电或复位，密码恢复为 123456，错误次数也会清零。
因此，设置密码后请在本次运行期间验收；本版本没有掉电保存密码功能。

十、接线和文件
蜂鸣器控制：PA1，网络标签仍为 LED1；高电平响、低电平静音。
矩阵键盘 C1/C2/C3/C4：PA8/PA7/PA6/PA5。
矩阵键盘 R1/R2/R3/R4：PA9/PA10/PA11/PA12。
LCD RS/RW/EN：PB5/PB6/PB7；D0～D7：PB8～PB15。

Keil 工程：代码\MDK-ARM\STM32F103C6.uvprojx。
Proteus 工程：仿真\STM32F103C6.pdsprj。
项目只保留一份仿真 HEX：仿真\密码锁.hex。
重新编译后，Keil 会生成“代码\MDK-ARM\DEMO\DEMO.hex”；
将其复制覆盖“仿真\密码锁.hex”，确认成功后可删除重复的 DEMO.hex。
旧录屏为存储柜操作，与本版电子密码锁流程不同，请以本说明为准。

十一、常见现象
LCD 没有显示：先检查仿真是否运行、U1 的 HEX 路径，再调整 LCD 对比度电位器。
输入不连续：每次按键后松开；长按只录入一次，同时按多个键不会正常录入。
按 D 没反应：确认已输入六位，并等待短暂提示或报警倒计时结束。
新密码开不了锁：确认两次输入一致并出现 PASSWORD CHANGED；若已复位，请用 123456。
第一次或第二次错误没有声音：这是正常行为，第三次连续验证失败才报警。
